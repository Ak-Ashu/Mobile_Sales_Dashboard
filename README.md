# 📱 Mobile Sales Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze mobile sales performance, customer behavior, transactions, and revenue trends.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Visualization

## 📈 Key Features

- Total Sales and Revenue analysis
- Quantity sold analysis
- Sales by mobile brand
- Sales by payment method
- Monthly and daily sales trends
- Customer and transaction analysis
- Interactive filters and slicers
- KPI cards
- Same Period Last Year analysis
- MTD sales analysis

## 🎯 Objective

The objective of this project is to transform raw mobile sales data into an interactive dashboard that helps analyze sales performance and identify business trends.
